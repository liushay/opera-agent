# 基于LangGraph主管‑工人架构多Agent知识库助手
## 项目简介
项目基于**主管‑工人**多智能体架构搭建知识库助手，可以自动拆解复杂任务、调度分工子智能体，完成知识库检索、数学计算、多节点结果汇总，适配复合型用户问题。

## 技术栈
Python3.11、LangChain、LangGraph、Chroma本地向量数据库、Ollama（qwen2‑7b大模型、nomic‑embed‑text向量化模型）、FastAPI‑Uvicorn、Pydantic

## 项目分层结构（工程化解耦）
1. **config**：存放全部全局可调参数，统一管理配置
2. **utils**：封装通用工具，包含文档文本分割、日志打印组件、函数级全局异常捕获装饰器
3. **kb_manager**：向量库业务模块，实现Chroma初始化、文档增量入库、文档去重、MMR多样性检索、相似度阈值过滤
4. **tools**：各类自定义工具函数封装（知识库查询、数值计算等）
5. **agent**
    - graph_base：具备反思循环机制的单智能体，检索资料不足时自动二次检索知识库
    - session_memory：基于session‑id实现多用户会话上下文隔离
    - multi_agent：主管‑工人模式多智能体调度核心，负责任务拆分、分配子Agent、汇总答案
6. **api后端服务层**
    使用FastAPI + uvicorn搭建接口，Pydantic做请求参数校验
    ### 接口列表
    - GET `/api/health`：服务健康检查
    - POST `/api/chat/normal`：支持会话记忆、反思机制的普通单Agent对话
    - POST `/api/chat/multi_agent`：主管‑工人多智能体对话入口

### 项目启动命令
```bash
uv run python api/main.py
```

## 核心功能特性
1. 通过session_id隔离每位用户独立的对话上下文，多用户互不干扰；
2. 全链路运行日志输出，可查看Agent每一步节点调度、工具调用流程；
3. 标准化JSON接口返回格式，装饰器实现全部业务函数统一异常捕获。

## 简历项目亮点
1. 采用分层式工程架构，业务模块解耦，所有超参集中配置，便于后期维护；
2. 向量知识库支持增量上传、重复文档过滤、MMR多样性检索优化，改善检索结果同质化问题；
3. 单Agent搭载反思循环逻辑，当检索素材不足以作答时自动发起二次知识库检索；
4. 实现多用户独立会话存储；
5. 主管‑工人多智能体任务拆解机制，不同子Agent负责专属任务，适配复杂复合型问题。

## 后续迭代优化方向
扩充工具调用智能体、联网搜索Agent、结果校验Agent；完善FastAPI后端服务，可对外提供Web对话服务入口。
