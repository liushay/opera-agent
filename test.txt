Agent 智能体是依托大语言模型作为核心推理底座，融合外部工具调用能力、私有知识库检索能力构建而成的智能化应用程序。它不再局限于大模型单次问答输出，能够自主拆解复杂任务、主动调用工具获取外部信息、依据知识库真实资料完成多步骤自主执行，具备自主规划、反思迭代的类人决策能力。
RAG 检索增强生成技术是解决原生大模型固有缺陷的核心方案，能够针对性弥补大模型两大痛点：一是训练数据固化带来的知识滞后问题，模型无法获取训练截止时间之后的全新资讯、企业内部更新文档；二是生成内容时无依据编造事实的幻觉问题，通过实时检索可信外部文档作为上下文约束大模型输出，让回答具备可溯源的真实依据，大幅提升专业场景下内容可信度。
LangChain 是一套面向大模型应用开发的标准化组件库，封装了文档加载、文本切分、向量存储、提示词管理、基础问答链等全套模块化工具，开发者无需从零编写底层逻辑，即可快速搭建检索问答、文档解析、简单对话等 LLM 落地应用；而 LangGraph 作为 LangChain 生态配套的智能体编排框架，专门用于实现具备循环、分支、反思、多轮迭代逻辑的复杂 Agent 流程，支持构建拥有自主思考、任务回滚、多步骤循环执行能力的高级智能体，解决传统线性链无法实现复杂任务闭环的短板。
